  1. Download on your phone

    Tap Download next to the app you want, then open the APK. If Android asks, allow your browser to install apps.

  2. YouTube needs MicroG-RE

    Install MicroG-RE once. It is what lets YouTube sign in to your Google account.

  3. Get updates by themselves

    Tap Add to Obtainium instead of Download. Obtainium installs the app and tells you whenever a new build is out.

Reddit and TikTok: these stable builds keep the app's own package name, so they cannot install over the Play Store app. Uninstall that one first (for TikTok you sign in again afterwards). YouTube and every pre-release build are renamed, so they install next to what you already have.

Obtainium asks "The app source is 'qutaiba-khader.github.io' but the release package comes from 'github.com'. Continue?" That is expected: the app's page is on this website and the APK is in this repository's GitHub releases. Tap Continue, and tick Don't show again to stop the question.

"Conflict" or "App not installed" means the same app is already on your phone from somewhere else, such as Morphe Manager or another builder, signed with a different key. Android cannot update across keys. Uninstall that copy once (back up its Morphe settings first if you want to keep them), then install from here. Every later update installs normally, because every APK here is signed with this repository's own key.

Every APK here is signed with the certificate SHA-256 . AppVerifier shows the same value for a genuine build.

Pick stable unless you want to try new things early. You can also have both.

Pre-release builds get their own package from the Clone app patch, which its authors say "does not work with all apps and may cause app crashes". If a pre-release build misbehaves, suspect that first.

Adding an app to Obtainium by hand

In Obtainium, tap Add App, paste the app's page below and choose the source HTML. Each page holds exactly one APK link and names the build version, app version plus patch version (for example 21.16.256-1.46.0), and Obtainium compares it with the version on the phone, so it offers an update when the app on the phone is older or the patches change.

…obtainium/youtube.html

Re-add each app once: links from before 10 October 2026 did not compare with the version on the phone, so an older app (one patched on the phone with the Morphe app, too) stayed "Up to date", and ObtainX ignored their +p1.46.0 part. Tap the app's Add to Obtainium button again and confirm Import: that replaces the settings and keeps the installed app. ObtainX does not replace an app it already lists (the link just opens it): remove the app from ObtainX's list first (that does not uninstall it), then tap the button. Right after that, a build installed outside Obtainium can show as a possible update once; install it from Obtainium and later builds arrive as normal updates. An update that fails at install means the app on the phone is signed with a different key: uninstall it once, then install from Obtainium. Obtainium checks every 6 hours; pull down on its list to check now. An app shown as Not installed offers Install, not an update. Always use the buttons; pasting a page address into Obtainium's own Add App screen creates an entry called "App" without these settings. api/obtainium.json has the ready-made settings for every app.

Every patch source in config.toml and the apps it can patch, read from its newest bundle with the Morphe CLI. To add one, see ADD.md.
