Obtainium

Each app also has an endpoint built for Obtainium, so your phone checks for updates on its own. Add it as an app of type HTML: 

…obtainium/youtube.html

The version is read from the APK filename, not from the release tag, so Obtainium only prompts when the app version actually changes. api/obtainium.json carries a ready-made config and a one-tap add link for every app.
